# 管理番号メーカー

ヤフオク・キャタウィキ・eBay の管理番号を作るだけのツールです。`index.html` 1ファイルで動きます（インストール不要）。

## 番号のルール

| 販路 | 並び | 例 |
| --- | --- | --- |
| ヤフオク | 通し番号(3桁) + 発送方法 + 月 + 撮影者 + 仕入者 + 発送サイズ(3桁) | 625DCgZ060 |
| キャタウィキ | 通し番号(4桁) + 年(西暦下1桁) + 月 + 仕入者 | 14676ER |
| eBay | 通し番号(4桁) + 年 + 月 + 仕入者 + -枝番（まとめ仕入れ時） | 52126ER-1 |

- 月は仕入日の月を英字にします（1月=A … 12月=L）。
- 仕入日・仕入元は番号に入れず、スプレッドシートに記入します。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`kanri-bango`）。
2. 「Add file」→「Upload files」で `index.html` と `README.md` をアップロードし、「Commit changes」。
3. 「Settings」→「Pages」→ Branch を `main` / `/(root)` にして「Save」。
4. 数分後に `https://<ユーザー名>.github.io/kanri-bango/` で開けます。スマホのホーム画面に追加しておくと便利です。

※ リポジトリを Public にすると、URLを知っている人は誰でも開けます（中身は仕入者名とコード表のみ）。社外に見せたくない場合は Private リポジトリ + 有料プラン、または社内PCで `index.html` を直接開いて使ってください。

## コード表を変えるとき

`index.html` の `// ===== コード表（変更はここだけ） =====` の部分を編集します。

- `BUYERS`：仕入者 `["名前","コード"]`
- `SHIPS`：発送方法
- `SIZES`：発送サイズ

## 履歴について

「履歴に追加」した番号は、その端末のブラウザにだけ保存されます。ほかの人・ほかの端末とは共有されません。重複チェックもその端末の履歴だけが対象です。
